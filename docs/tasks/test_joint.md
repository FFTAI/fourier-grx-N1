# 关节运动功能测试

## 任务信息

任务值 (TID): **902**

任务描述：

- 机器人关节运动功能测试，用于检测机器人关节是否能够正常运动。
- 任务执行时，机器人会先缓慢运动到正弦测试的起始位置（约 5 秒），然后 **逐个关节** 进行小幅度正弦摆动测试：
    - 每测试一个关节前，程序会等待 3 秒，并打印当前待测试的关节序号。
    - 被测关节绕起始位置做正弦摆动（默认频率 0.5 Hz，重复 3 个周期），其余关节保持在起始位置不动。
    - 完成一个关节的测试后，自动切换到下一个关节，直至所有关节测试完毕。
- 该任务通过 PD 控制方式执行，适用于机器人出厂检测或故障排查时，快速定位无法正常工作
  的关节。

> ⚠️ **注意**：
>
> 执行该任务前，请确保机器人已正确固定（如悬挂在吊架上或做好防摔保护），
> 防止关节摆动过程中机器人倾倒造成损坏。
