# 参考指南

本章汇总 Fourier-GRX-N1 SDK 的核心参考资料，包括三类接口说明、运行模式、命令行工具、配置文件以及系统运行逻辑。

如果您已经完成基础安装并准备开始开发，建议优先阅读与当前开发方式对应的接口说明，再结合运行模式和配置文件文档完成环境配置。

* TOC
{:toc}

## 阅读建议

- 使用 User 接口进行上层应用开发时，优先阅读 [User 接口](/fourier-grx-N1/docs/reference/user) 与 [运行模式](/fourier-grx-N1/docs/reference/run_type)。
- 使用 Developer 接口进行底层控制开发时，优先阅读 [Developer 接口](/fourier-grx-N1/docs/reference/developer)、[启动配置文件](/fourier-grx-N1/docs/reference/config_file) 与 [系统运行逻辑](/fourier-grx-N1/docs/reference/system_running_logic)。
- 使用 PubSub 接口进行远端通信开发时，优先阅读 [PubSub 接口](/fourier-grx-N1/docs/reference/pubsub) 与 [运行模式](/fourier-grx-N1/docs/reference/run_type)。
