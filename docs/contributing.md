# 贡献指南

如有发现文档中的问题，欢迎给我们[文档仓库](https://github.com/FFTAI/fourier-grx-N1)提 issue 以及改进的 pull-request，我们会尽快处理。

## 贡献范围

本仓库主要维护 Fourier-GRX-N1 SDK 的文档内容，包括：

- `index.md` 与 `README.md` 等入口说明
- `docs/` 下的快速开始、示例代码、参考指南、任务说明、训练说明与常见问题
- `assets/images/` 下被文档引用的图片资源

## 提交前建议

- 优先保持现有页面结构和导航关系不变，新增内容时尽量放到对应章节下。
- 修改文档中的链接、图片或任务编号时，请同步检查相关交叉引用页面是否仍然一致。
- 如果变更涉及 SDK 行为、任务值（TID）、模块值（MID）或运行模式，请以当前文档和实际发布说明为准。

感谢 Fourier-GRX-N1 SDK 社区的贡献者们！🎉
