# 快速开始

本章用于帮助用户快速完成 N1 机器人的基础上电、登录系统、启动程序以及进入二次开发流程。

如果您是第一次接触 Fourier-GRX-N1，建议先按照本章顺序完成环境准备，再继续阅读 [示例代码](/fourier-grx-N1/docs/examples) 和 [参考指南](/fourier-grx-N1/docs/reference)。

* TOC
{:toc}

## 推荐阅读顺序

1. 阅读 [N1 机器人](/fourier-grx-N1/docs/quickstart/n1)，完成开机、登录和程序启动。
2. 阅读 [常用操作](/fourier-grx-N1/docs/usage)，了解安装、校准和日志相关操作。
3. 阅读 [示例代码](/fourier-grx-N1/docs/examples)，选择合适的接口层开始二次开发。
